# KREAM 리셀 마진 계산기

크림(KREAM) 리셀러를 위한 마진 및 수익률 계산기 웹앱입니다.  
아울렛/매장 할인 구매가와 크림 판매 수수료 및 배송비를 고려하여 최종 정산금액과 순수익, 수익률을 실시간으로 계산하고 관리할 수 있습니다.

## 주요 기능
- **실시간 마진 산출**: 매장 표시 가격, 추가 할인율(%), 크림 수수료율(%), 배송비를 종합하여 정산 입금액과 예상 순수익, 수익률 즉시 계산
- **설정값 자동 저장**: 수수료율 및 택배비 설정은 로컬 스토리지에 자동 저장되어 재접속 시에도 유지 (기본값 복원 기능 제공)
- **히스토리 저장 및 관리**:
  - 제품명, 수량(개수), 메모와 함께 계산 결과 저장
  - **제품 사진 첨부**: 브라우저 자동 이미지 압축(30~50KB) 및 IndexedDB 대용량 저장소 탑재로 수백 장의 사진도 용량 걱정 없이 영구 보관 (사진 탭 시 확대보기 지원)
  - 저장된 히스토리 목록 조회 및 누적 순수익 요약 (수량 반영)
  - 제품명/수량/사진/메모 수정, 개별 삭제 및 전체 삭제
  - 히스토리 데이터를 계산기로 다시 불러오기
- **휴대폰 사진첩 영수증 저장**: 계산 결과 또는 히스토리 항목(제품 사진 포함)을 고화질 마진 영수증 이미지로 생성하여 휴대폰 사진첩에 저장 및 공유 (Web Share API 지원)
- **데이터 백업 및 복원**:
  - **파일 백업 (JSON)**: 사진 데이터가 포함된 완전한 백업 파일을 스마트폰 '파일' 앱 또는 컴퓨터에 저장
  - **파일 복원**: 백업 파일(.json)을 불러와 기존 데이터와 병합 또는 복원
  - **엑셀(CSV) 내보내기**: 스프레드시트 분석을 위한 CSV 다운로드
- **PWA/모바일 웹앱 최적화**: 스마트폰 홈 화면에 추가하여 앱처럼 사용 가능, 눈에 띄지 않는 원터치 새로고침 버튼 지원
